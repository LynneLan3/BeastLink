## Minimum PC requirements

Steam currently lists these BeastLink minimum values:

| Requirement | Minimum listed value |
| --- | --- |
| Operating system | Windows 10 |
| Memory | 16 GB RAM |
| DirectX | Version 12 |
| Graphics | RTX 2060 or RX 5600 XT minimum-class graphics |
| Storage | 30 GB available space |
| Network | Broadband internet connection |

## Published memory guidance

The same Steam listing gives **32 GB RAM** as its recommended memory value. This page does not fill in additional recommended CPU or GPU values that are not recorded in the research evidence.

The requirements were checked on 2026-08-11 and may change during Early Access. Verify the current Steam listing before purchase or installation.
