## When does BeastLink Early Access start?

Steam lists BeastLink Early Access for **August 18, 2026**. The official BeastLink website also communicates an **August 2026** Early Access window.

The store snapshot checked on 2026-08-11 still presented the product as not yet released. This is a time-sensitive status and may change as the launch window arrives.

## Developer and platform context

- **Developer / publisher:** Grove Street Games
- **Confirmed store platform:** PC via Steam

The reviewed sources do not confirm a console store release. This Guide therefore does not imply PlayStation, Xbox, or Nintendo availability.

For current Early Access gameplay details, see [BeastLink gameplay](/beastlink/gameplay/). For PC hardware requirements, see [BeastLink system requirements](/beastlink/system-requirements/).
