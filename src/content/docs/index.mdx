## Confirmed game scope

**BeastLink** is a giant multiplayer Kaiju game from Grove Street Games. The official site and Steam listing describe collisions between humans, vehicles, and Beasts in destructible urban environments, with serum-based BeastLinking and SuperDestruction as core concepts.

Because this is an Early Access title, the current Guides distinguish stable identity and release information from the time-sensitive snapshot in Steam's developer FAQ.
